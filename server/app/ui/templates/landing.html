How it works

Three steps, no changes to your application, and no lock-in to a CI system.

  1. 1

    Scan

    The open-source mergeclear CLI parses your code with tree-sitter on a laptop, in any pipeline or in a git hook. No build, no running app, no annotations. It finds endpoints, request and response models, validation, security and every database, cache, queue and HTTP call.

  2. 2

    Check

    mergeclear check compares your branch with the base and exits non-zero on Hold, so any CI can gate a merge. It also writes a Markdown summary you can post on the pull request.

  3. 3

    Explore

    Push reports to your self-hosted server for versioned docs written by your local model, the architecture map, impact across services and QA plans.

Private by default

Self-hosted. Your code is analysed on your own machines and documentation is written by a local model. Nothing is sent to a third-party service.

Try it on a repository

Install the scanner from the Mergeclear repository

pipx install ./scanner

Check your branch against main: prints the verdict, exits 1 on Hold

mergeclear check --base origin/main

Send scans to your Mergeclear server with an API key from Settings → API keys

MERGECLEAR_API_KEY=… mergeclear scan --push https://mergeclear.internal
